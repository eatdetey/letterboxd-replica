# Ручное тестирование

## Регистрация и логин

### Тест 1: Успешная регистрация
**Предусловие:** Пользователь не зарегистрирован  
**Шаги:**
1. Открыть страницу регистрации
2. Ввести валидный email
3. Ввести пароль
4. Подтвердить пароль
5. Нажать "Зарегистрироваться"  
**Ожидаемый результат:** Аккаунт успешно создан, пользователь авторизован или перенаправлен на логин  
**Фактический результат:** Пользователь успешно создаётся и система выполняет вход либо открывает страницу авторизации
**Статус:** Выполнен


### Тест 2: Успешный логин
**Предусловие:** Пользователь зарегистрирован  
**Шаги:**
1. Открыть страницу логина
2. Ввести корректные данные
3. Нажать "Войти"  
**Ожидаемый результат:** Пользователь входит в систему  
**Фактический результат:** После ввода корректных данных пользователь получает доступ к своему аккаунту
**Статус:** Выполнен


### Тест 3: Логин с неверным паролем
**Шаги:**
1. Ввести корректный email
2. Ввести неверный пароль
3. Нажать "Войти"  
**Ожидаемый результат:** Отображается ошибка "Неверный логин или пароль"  
**Фактический результат:** Система выводит сообщение о неправильных учетных данных и не выполняет вход
**Статус:** Выполнен


### Тест 4: Регистрация с пустыми полями
**Шаги:**
1. Оставить поля пустыми
2. Отправить форму  
**Ожидаемый результат:** Отображаются ошибки валидации  
**Фактический результат:** Форма не отправляется и пользователю показываются сообщения о необходимости заполнения полей
**Статус:** Выполнен



## Работа со списком фильмов

### Тест 5: Создание списка фильмов
**Предусловие:** Пользователь авторизован  
**Шаги:**
1. Перейти в раздел "Мои списки"
2. Нажать "Создать список"
3. Ввести название списка
4. Сохранить  
**Ожидаемый результат:** Список создан и отображается  
**Фактический результат:** Новый список появляется в разделе пользователя и доступен для просмотра
**Статус:** Выполнен


### Тест 6: Создание списка с пустым названием
**Предусловие:** Пользователь авторизован  
**Шаги:**
1. Нажать "Создать список"
2. Оставить название пустым
3. Сохранить  
**Ожидаемый результат:** Ошибка валидации  
**Фактический результат:** Система блокирует создание списка и показывает сообщение об ошибке
**Статус:** Выполнен



## Добавление фильма в список

### Тест 7: Добавление фильма в список
**Предусловие:** Есть созданный список  
**Шаги:**
1. Открыть страницу фильма
2. Нажать "Добавить в список"
3. Выбрать список  
**Ожидаемый результат:** Фильм добавлен в список  
**Фактический результат:** Выбранный фильм успешно появляется в указанном списке
**Статус:** Выполнен



### Тест 8: Добавление фильма без авторизации
**Шаги:**
1. Попробовать добавить фильм в список  
**Ожидаемый результат:** Требуется авторизация  
**Фактический результат:** Система запрашивает вход в аккаунт и не выполняет действие
**Статус:** Выполнен

**Статус:** Выполнен

**Шаги:**

2. Отправить

**Фактический результат:** Отправка не происходит, система уведомляет о необходимости заполнения поля
**Статус:** Выполнен



## Проверка прав доступа
