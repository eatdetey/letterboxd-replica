# Набор тест-кейсов для системы фильмов

## Поиск фильмов по названию

### Тест-кейс 1: Успешный поиск фильма по точному названию
**Предусловие:** Пользователь находится на главной странице  
**Шаги:**
1. Ввести точное название фильма в поле поиска
2. Нажать кнопку поиска  
**Ожидаемый результат:** Отображается список фильмов, содержащий искомый фильм


### Тест-кейс 2: Поиск фильма по частичному названию
**Шаги:**
1. Ввести часть названия фильма
2. Выполнить поиск  
**Ожидаемый результат:** Отображается список фильмов, соответствующих запросу


### Тест-кейс 3: Поиск несуществующего фильма
**Шаги:**
1. Ввести случайный набор символов
2. Выполнить поиск  
**Ожидаемый результат:** Отображается сообщение "Ничего не найдено"

### Тест-кейс 8: Добавление отзыва

**Ожидаемый результат:** Отзыв удален
