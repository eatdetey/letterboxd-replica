## 1. Источники данных

Были рассмотрены несколько API-источников, предоставляющих данные о фильмах.

| Источник                    | Лимиты              | Язык    | Доступ из РФ   |
|-----------------------------|---------------------|---------|----------------|
| TMDb API                    | 50 запросов/сек     | русский | через VPN      |
| Kinopoisk API Unofficial    | 500 запросов/сутки  | русский | да             |
| poiskkino.dev               | 200 запросов/сутки  | русский | да             |

---

## 2. Лучший источник данных

В качестве основного источника данных выбран TMDb API (The Movie Database), поскольку:
1) Используется сервисом Letterboxd в качестве основного источника данных.
2) Лимит 50 запросов/сек.
3) Хранит следующие данные: название, постер, год, жанры, описание, средний рейтинг, актёры, режиссёры, сценаристы, трейлеры, похожие фильмы.
4) Требуется VPN на этапе сбора данных и формирования датасета.
5) Есть русская локализация.

---

## 3. Количество данных

1) 100 фильмов с наивысшим пользовательским рейтингом (по данным TMDb), endpoint: /movie/top_rated.
2) 250 самых популярных фильмов на текущий момент, endpoint: /movie/popular.
3) 500-1000 новинок последних 2-3 лет по дате релиза.
4) 500-1000 фильмов разных десятилетий.
5) 500 фильмов разных жанров.
Допускается пересечение пунктов 1 и 2.

Итого: 1850-2850 фильмов.

Выбранный объём данных является достаточным для реализации функционала сервиса и проведения аналитической обработки.
При этом он не создаёт избыточной нагрузки на процесс сбора и обработки данных и обеспечивает репрезентативность выборки.
