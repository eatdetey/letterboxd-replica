# Пользовательские истории (User Stories)

## 1. Незарегистрированный пользователь (Гость)

Как **незарегистрированный пользователь**, я хочу:

- **...искать фильмы по названию,** чтобы быстро находить интересующие меня картины.
- **...просматривать детальную информацию о фильме** (описание, актеров, год выпуска), чтобы решить, стоит ли его смотреть.
- **...просматривать список фильмов** (например, популярные или новинки), чтобы выбрать кино для просмотра.
- **...читать отзывы к фильмам,** чтобы узнать мнение других зрителей перед просмотром.
- **...просматривать профили других пользователей,** чтобы видеть их активность и список оцененных фильмов.
- **...зарегистрироваться,** чтобы получить доступ к расширенному функционалу (возможность оценивать и писать отзывы).
- **...авторизоваться в аккаунте,** чтобы войти в свой профиль и управлять контентом.

---

## 2. Зарегистрированный пользователь

Как **зарегистрированный пользователь**, я хочу:

- **...искать фильмы по названию,** чтобы быстро находить нужные фильмы для оценки или просмотра.
- **...просматривать детальную информацию о фильмах,** чтобы принимать решение об их оценке.
- **...просматривать список фильмов,** чтобы открывать для себя новый контент.
- **...читать отзывы к фильмам,** чтобы понимать сильные и слабые стороны картины.
- **...ставить оценку фильму,** чтобы выражать свое мнение и влиять на общий рейтинг.
- **...писать отзывы к фильмам,** чтобы делиться развернутым мнением с сообществом.
- **...удалять свои отзывы к фильмам,** чтобы исправлять ошибки или скрывать устаревшее мнение.
- **...редактировать свой профиль** (аватар, описание, личные данные), чтобы персонализировать аккаунт.
- **...просматривать профили других пользователей,** чтобы находить людей со схожими вкусами и смотреть, что нравится им.
- **...выходить из профиля,** чтобы обеспечить безопасность аккаунта на общих устройствах.
