# API Automation Suite

Тесты написаны на **Python** с использованием фреймворка **Pytest**.

Перед запуском тестов убедитесь, что в файлах указан актуальный `BASE_URL` и валидный `AUTH_TOKEN` (для тестов Movie и Playlist сервисов).

Реализованы проверки для трех основных микросервисов:

| Сервис | Сценарий | Описание проверки |
| :--- | :--- | :--- |
| **User Service** | Регистрация | Успешное создание, проверка структуры ответа. |
| | Регистрация | Проверка обработки ошибки при попытке создать существующего юзера. |
| | Авторизация | Вход под созданным пользователем и получение токенов. |
| **Movie Service** | Поиск фильмов | Поиск по строке, валидация типов данных. |
| | Отзывы | Получение списка отзывов для конкретного фильма по его `ID`. |
| **Movie List** | CRUD Плейлиста | Полный цикл: Создание -> Проверка в списке -> Переименование -> Удаление. |

---

**Запустить все тесты**
`pytest`

**Запустить тесты с подробным логированием (Verbose)**
`pytest -v`

**Запустить конкретный файл**
`pytest tests/test_user_service.py`
